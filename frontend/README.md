# Extension Icons

You need to create the following icon files for Chrome Web Store submission:

## Required Files

| File | Size | Usage |
|------|------|-------|
| `icon16.png` | 16x16 px | Toolbar icon |
| `icon48.png` | 48x48 px | Extensions page |
| `icon128.png` | 128x128 px | Chrome Web Store |

## Quick Options to Create Icons

### Option 1: Online Generator (Easiest)
1. Go to https://favicon.io/favicon-generator/
2. Enter "S" as the text
3. Choose a background color (e.g., #6366f1 - indigo)
4. Download and rename files

### Option 2: Canva (Free)
1. Go to canva.com
2. Create designs at 128x128
3. Export and resize for 48 and 16

### Option 3: Use an AI Image Generator
Prompt: "Simple modern app icon for an AI reading assistant, letter S, minimalist, purple gradient, rounded square"

## Suggested Design

A simple "S" on a purple/indigo gradient background:
- Background: Linear gradient from #6366f1 to #8b5cf6
- Letter: White, bold, modern font
- Shape: Rounded square corners
