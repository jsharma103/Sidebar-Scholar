# Chrome Web Store Screenshot Guide

## Requirements

- **Minimum:** 1 screenshot required
- **Recommended:** 3-5 screenshots
- **Size:** 1280x800 or 640x400 pixels
- **Format:** PNG or JPEG

## How to Take Screenshots

### Method 1: Chrome DevTools (Recommended)

1. Open Chrome and load your extension
2. Navigate to a webpage (e.g., Wikipedia article, news site)
3. Open the extension sidebar
4. Press `F12` or `Cmd+Option+I` (Mac) to open DevTools
5. Click the device toolbar icon (or press `Cmd+Shift+M`)
6. Set custom dimensions: 1280x800
7. Take a screenshot:
   - Mac: `Cmd+Shift+P` → type "Capture screenshot"
   - Windows/Linux: `Ctrl+Shift+P` → type "Capture screenshot"
8. Select "Capture screenshot" (not "Capture node screenshot")

### Method 2: Browser Extension

1. Install a screenshot extension like "Awesome Screenshot" or "Nimbus Screenshot"
2. Set capture area to 1280x800
3. Capture the browser window with sidebar visible

### Method 3: macOS Screenshot Tool

1. Open the extension sidebar on a webpage
2. Press `Cmd+Shift+4`
3. Drag to select 1280x800 area
4. Save the screenshot

## Suggested Screenshots

### Screenshot 1: Main Feature (Required)
**What to show:**
- Sidebar open with a question and answer visible
- A webpage in the background (e.g., Wikipedia article)
- The chat interface showing a helpful response

**Example scenario:**
- Navigate to a Wikipedia article about "Machine Learning"
- Open sidebar
- Ask: "What is machine learning?"
- Capture when answer is displayed

### Screenshot 2: Settings Panel
**What to show:**
- Settings panel open
- API provider selection visible
- Backend URL configuration
- Clean, organized interface

### Screenshot 3: Multiple Questions
**What to show:**
- Chat history with multiple questions/answers
- Shows the conversational nature of the extension
- Different types of questions (summary, explanation, etc.)

### Screenshot 4: Keyboard Shortcuts in Action
**What to show:**
- Text selected on a webpage
- Sidebar open with selected text pasted
- Demonstrates the keyboard shortcut feature

### Screenshot 5: Different Website Context
**What to show:**
- Extension working on a different type of site
- E.g., technical documentation, news article, blog post
- Shows versatility

## Tips

- **Use high-quality content:** Choose webpages with good content that showcases the extension well
- **Clean UI:** Make sure the sidebar looks clean and professional
- **Good contrast:** Ensure text is readable
- **Show value:** Screenshots should clearly show what the extension does
- **Consistent style:** Use similar browser window sizes and layouts

## File Naming

Save screenshots as:
- `screenshot-1-main-feature.png`
- `screenshot-2-settings.png`
- `screenshot-3-chat-history.png`
- etc.

## Where to Save

Save screenshots in this `store-assets/` folder. They will NOT be included in the extension ZIP file.

## Upload to Chrome Web Store

When submitting to Chrome Web Store:
1. Go to the store listing page
2. Upload screenshots in the "Screenshots" section
3. Add captions if desired (optional but helpful)
4. At least 1 screenshot is required, but 3-5 is recommended for better visibility
